# G137 analysis plan

## Design

Run a six-person pilot followed by a separately preregistered 24-person main
study. Each phase is split evenly between general and functional programmers.
Within each stratum, alternate semantic-foundation-first and
public-language-first orders; odd totals differ by at most one assignment.
The public-language condition cannot run until P107 and P109 are complete.

The pilot checks task ambiguity, duration bands, rubric agreement, and whether
the four outcome metrics can be scored from minimized codes. Pilot observations
do not count toward the main result. After the pilot, freeze numerical pass
thresholds for prediction accuracy, task completion, transfer success, and
repair success before enrolling a main-study participant.

## Analysis

Report participant and task counts, condition order, stratum, each outcome
proportion, paired within-participant differences when both conditions exist,
and uncertainty intervals suitable for the small sample. Report general and
functional strata separately and together. Duration bands are descriptive and
cannot substitute for correctness.

Retain incorrect and abandoned outcomes. Apply only the predefined exclusions:
withdrawn consent, duplicate participation, or facilitator protocol failure.
Report every exclusion with its reason and phase. Do not remove an outlier,
failed task, or inconvenient result after inspecting outcomes.

## Gate decision

G137 remains blocked while observed human evidence is absent, while either
public condition is held, before main-study thresholds are preregistered, or
when the retained aggregate cannot reproduce all metric totals and exclusions.
An agent simulation, expert opinion, preference poll, or prepared package does
not satisfy the gate.
