# G137 usability pre-study package

This directory contains the executable, grammar-independent preparation for
Catena's usability gate. It does not contain participant observations or a
claim that G137 has passed.

The package fixes the study phases, programmer strata, task families,
counterbalancing rule, minimized data fields, exclusions, and outcome kinds.
Public vocabulary and source conditions remain held for P107 and P109. Run
`mix test test/catena/usability_study_test.exs` from the repository root to
validate the package and its blocked evidence state.

Files:

- `study-package.json` is the machine-readable pre-study record.
- `consent-and-data.md` is the participant consent and data-minimization text.
- `facilitator-guide.md` fixes session conduct and intervention boundaries.
- `semantic-task-book.md` defines vocabulary-neutral task prompts and scoring keys.
- `analysis-plan.md` fixes counterbalancing, metrics, exclusions, and the
  pilot-to-preregistration transition.

No outreach is authorized by these files. Before any recruitment, the study
owner must supply separate authorization and an approved contact channel.
