# Runtime Specs Index

This index covers the promoted runtime-domain surfaces.

- [effect_runtime.md](effect_runtime.md)
- [actor_runtime.md](actor_runtime.md)
- [repl_runtime.md](repl_runtime.md)

These specs focus on the actual runtime boundaries that exist today rather
than the full future runtime story. The effect and REPL boundaries include
opaque process-affine resumptions, deep/shallow restoration, bounded
admissible multi-shot branches, canonical compiler-backed sessions, and safe
control tracing.
