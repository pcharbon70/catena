# Catena documentation

This directory contains code-oriented documentation that benefits from a
stable hierarchy separate from the task-oriented material in
[`guides/`](../guides/README.md).

## Guides

- [Developer guides](guides/developer/README.md) explain the exact 0.1.8
  semantic-kernel implementation one boundary at a time, from source bytes to
  reference execution or a deterministic BEAM artifact.

The existing [Catena Guides](../guides/README.md) remain the primary learning
path for language users, compiler contributors, and operators.

- [Trusted computing base](trusted-computing-base.md) maps guarantees to their
  enforcement, residual host assumptions and reviewed source/data boundary gate.

- [Trusted obligation policy](trusted-obligation-policy.md) — exact transitive disclosure and scoped foreign/native admission.
